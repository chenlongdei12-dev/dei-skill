# 数据契约与成熟窗口

## 标准字段

保留 `video_id`、`description`、`published_at`、`duration_sec`、`views`、`likes`、`favorites`、`comments`、`shares`、留存、主页、涨粉和业务转化字段。所有比率统一为0—1；作品ID保存为字符串。

新增：

- `snapshot_at`：本次数据观察时间；优先使用原字段，其次CLI参数，再其次文件名日期，最后才用文件修改时间。
- `observation_age_days`：`snapshot_at - published_at`。
- 固定窗口字段：`{metric}_24h / _72h / _7d / _30d`。
- `metric_window`：必须写明是固定窗口还是 `cumulative_as_of_snapshot`。

累计值不得冒充7天表现。不同成熟度作品的累计互动只能用于探索性比较。

## 能力按轴声明

不要只写A/B/C；同时声明：

- `exposure`：是否有播放；
- `retention`：是否有开头留存、平均观看或完播；
- `engagement`：是否有至少三种互动；
- `conversion`：是否有主页、涨粉或业务结果；
- `fixed_window`：是否有固定观察窗口。

能力轴默认要求对应字段覆盖至少80%的作品；零星几条有数据只能报告覆盖率，不能升级能力。

A：曝光＋留存＋转化；B：至少三种互动；C：只有内容或不完整指标。能力轴比等级更优先。

## 数据质检

1. 重复作品ID保留字段最完整的一条，并输出所有源行。
2. 负值、比率超界、发布日期晚于观察日、平均观看明显超过时长进入异常清单。
3. 输出字段覆盖率和成熟度分布。
4. 逐字稿匹配同时输出方法、得分和歧义；最佳候选与次佳候选差距过小时保留未匹配。
5. 匹配率低于80%时，未匹配作品只能进入账号总体统计。

## 比较规则

- 以中位数和分位数为主，同时保留均值用于发现极值影响。
- 同主题、时长、形式、观察窗口和邻近时间优先配对。
- 使用作品发布前的滚动基准，不能让未来数据进入历史判断。
- 少于3条不排名；少于10条不称稳定规律。
- 综合互动指数只用于浏览样本，不是统一成败指标。
- 业务目标决定主指标，禁止用一个固定权重指数替代播放、留存或成交。
