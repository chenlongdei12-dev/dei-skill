# 数据嵌入创作工作流

## 素材优先级

1. 已通过来源校验的内容单元。
2. 主题地图与选题装配稿。
3. 用户本人已发布逐字稿。
4. 用户本人未发布成熟稿件。
5. 外部材料；必须标明外部来源，不得改写成个人经历。

若项目使用 `OPI/CNT/MOD/CON/CAS/EVD/SOL` 等内容单元，优先装配：

- `CNT + OPI + MOD`：旧认知、反转、新框架。
- `CAS + OPI + SOL`：具体故事、核心判断、行动路径。
- `CON + OPI + EVD`：重新定义、判断、论证。

缺少反例、新框架或证据时标记内容缺口，不要用语言技巧掩盖。

## 从历史数据到新稿

1. 选择业务目标、主指标和固定观察窗口。
2. 选择一个已验证内容公式或待验证假设。
3. 只改变一个主要变量，同时记录不能完全控制的维度。
4. 从素材库选择能支撑新框架的真实单元。
5. 检查语义终点是否机械回到旧概念，并补充现实机制或真实条件。
6. 写两个钩子版本和一份主体稿。
7. 若进入预测，先登记预测ID、目标、概率、置信和限制；实验性预测不得作为必发依据。
8. 进行来源、逻辑、口播和去模板化检查。
9. 记录发布ID、数据抓取节点和复盘日期。

## 质量检查

- 前3秒是否出现清晰冲突或收益，而不是寒暄。
- 新框架是否真正替代旧框架，而不是只说“你要爱自己”。
- 是否区分事实、解释、假设和战略选择。
- 是否说明金钱、时间、权力、责任、信息或选择代价中的至少一个相关现实条件；若确实无关，不强加。
- 每个案例、数字和个人经历是否有来源。
- 句子是否适合口播；长句有自然呼吸点。
- 是否保留IP已有的认知方式，但避免机械复刻高频词与句式。
- CTA 是否服务本条业务目标。
