# 内容DNA与语义复核

## 必填维度

每条内容至少记录：目标人群、具体处境、主要矛盾、主主题、次主题、开头动作、内容承诺、价值结构、解释机制、证据类型、语义终点、现实机制、情绪功能、人格姿态、CTA、形式、时长。

重点新增：

- `semantic_endpoint`：结论最终落到主体性/向内、爱自己、认知提升、关系行动、现实选择与代价、开放问题或其他。
- `reality_mechanism`：是否讨论金钱资源、权力、责任照护、时间注意力、选择代价或信息事实。
- `evidence_type`：数据、权威引用、个人经历、人物案例、行为观察、类比或纯断言。

## 标签分层

1. 脚本规则只生成 `_draft` 候选。
2. Agent 阅读开头、核心论证和结尾后生成 `_reviewed`。
3. 标题话题标签与正文主题分开；不能因为出现 `#女性成长` 就判定正文主要讨论女性现实。
4. 多主题内容必须选一个主要矛盾，其他主题作为次标签。
5. 无法判断时标记“未知”，不得强配。

## 复核条件

- 反转必须同时存在旧认知A与修正判断B。
- 案例必须有主体、动作和可定位细节。
- 步骤模型至少有两个共享判断维度的结构项。
- 现实机制必须指出资源、权力、责任、时间、代价或事实怎样改变选择。
- 语义终点以结尾实际完成的解释动作判定，不以单个词判定。
- “主体性、内核、爱自己”若能无差别套到其他事件，标记为高重复终点。

## 公式记录

公式写成：

```text
人群 + 处境 + 矛盾 + 开头动作 + 解释机制 + 证据 + 语义终点 + 情绪 + CTA + 形式/时长
```

同时保存支持作品、反例作品、样本数、数据期、观察窗口、相对滚动基准、证据能力、状态和下一次验证。宽主题不得单独称为公式。
