# 内容实验规范

## 设计

每个实验只设一个主要变化，同时记录无法完全控制的共同变化。优先使用同主题、同时长层、相近发布时间和相同观察窗口的配对或区组。

实验必须包含：假设、主指标、观察窗口、对照、实验组、控制维度、最小样本、复盘日、支持/拒绝/不确定裁决规则。

## 最小判断

- 单条爆款只进入复验。
- 每组少于3条时只记录观察。
- 至少两轮方向一致才称初步支持。
- 未按计划发布与策略失败分开。
- 多个变量同时变化时，结果标记 `inconclusive`。

## 执行评分

```text
执行分 = 发布完成率×35% + 配比执行率×20% + 结构执行率×15%
       + 实验完成率×20% + 复盘完整度×10%
```

按实际计划周期计算。执行分低于60%时，先修执行负荷，不裁决策略。
